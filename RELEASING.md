# Release checklist

The repository is ready to publish. Steps, in order.

## 1. GitHub
```bash
cd dracp-release
git init && git add . && git commit -m "Initial release: DRACP v0.1.0"
git branch -M main
git remote add origin https://github.com/<you>/dracp.git
git push -u origin main
```
`data/`, `results/` and `logs/` are git-ignored: they are regenerated by `./run.sh`,
which keeps the repository small (~0.5 MB instead of 135 MB). If you want to publish
the exact result files used in the paper, attach them as a GitHub Release asset or
deposit them separately on Zenodo — do not commit them.

Update the placeholder URLs (`bogdanoancea/dracp`) in `pyproject.toml`,
`CITATION.cff` and `README.md` if your repository name differs.

## 2. Zenodo DOI
1. Sign in to Zenodo with GitHub, and enable the switch for this repository.
2. On GitHub, create a release (tag `v0.1.0`).
3. Zenodo archives that snapshot and mints a DOI; a "concept DOI" also covers all
   future versions.
4. Add the DOI badge to `README.md` and cite the DOI in the paper.

Do this at submission time, so referees can access a frozen, citable snapshot.

## 3. PyPI (optional but recommended)
First check the name is free: https://pypi.org/project/dracp/
If taken, rename the project in `pyproject.toml` (e.g. `dracp-conformal`).

Publishing uses Trusted Publishing (OIDC) — no API tokens in the repository:
1. On PyPI: Account → Publishing → add a trusted publisher with
   owner `<you>`, repository `dracp`, workflow `publish.yml`, environment `pypi`.
2. On GitHub: Settings → Environments → create `pypi`.
3. Create the GitHub release; `.github/workflows/publish.yml` builds and uploads.

To test the flow first, publish to TestPyPI by adding
`with: repository-url: https://test.pypi.org/legacy/` to the publish step.

## 4. Verify
```bash
pip install dracp
python -c "from dracp import ConformalForecaster; print('ok')"
```

## Local build check (already verified)
```bash
python -m build && python -m twine check dist/*
```
produces a ~21 KB wheel containing only the `dracp` package.
